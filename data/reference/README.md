# Справочник IT-должностей и навыков (источник: hh.ru, Россия, удалённая работа)

## Структура файлов

Каждый CSV-файл (лист Excel) = таблица БД. Первая строка — имена колонок, ID — стабильные ключи.

| Файл | Описание |
|---|---|
| `roles.csv` | Должности. `parent_role_id` задаёт иерархию (Python-разработчик → Backend-разработчик). `hh_professional_role_id` — id роли в справочнике hh (`api.hh.ru/professional_roles`). |
| `role_synonyms.csv` | Синонимы и варианты написания должности (1 строка = 1 синоним). |
| `skills.csv` | Навыки, технологии, методологии. `category` — тип навыка. |
| `skill_synonyms.csv` | Синонимы навыка: сокращения, русские и английские написания, версии, смежные инструменты. |
| `role_skills.csv` | Связь «должность ↔ навык». `importance`: `core` (ядро) или `common` (часто встречается). |
| `hh_search_config.csv` | Параметры поиска на hh: `area=113` (Россия), `work_format=REMOTE` (старый параметр `schedule=remote`), `professional_role`, строки запроса. |

Колонки с пометкой «(справочно)» — удобные для чтения копии названий, в БД их не грузить.

## Перенос в БД

Каждый CSV загружается как таблица (`COPY` / `LOAD DATA` / `pandas.to_sql`). Связи по id:

- `role_synonyms.role_id` → `roles.role_id`
- `skill_synonyms.skill_id` → `skills.skill_id`
- `role_skills.role_id` → `roles.role_id`, `role_skills.skill_id` → `skills.skill_id`
- `roles.parent_role_id` → `roles.role_id`

Кодировка CSV: UTF-8 с BOM.

## Важно

- Справочник собран экспертно на основе таксономии должностей hh и типовых требований вакансий; живые вакансии hh из этой среды не выгружались (нет доступа к api.hh.ru). Для частотной проверки и дополнения словаря используйте hh_collect.py — он выгружает вакансии и считает key_skills.
- hh_professional_role_id нужно сверить со справочником api.hh.ru/professional_roles (пусто — не уверен). Списки синонимов — стартовые, расширяются по результатам выгрузки.
- Объём: ролей 53, синонимов ролей 375, навыков 140, синонимов навыков 964, связей роль-навык 702.
