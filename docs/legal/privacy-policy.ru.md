# Политика конфиденциальности

## 1. Общие положения

Эта политика описывает, как оператор обрабатывает персональные данные пользователей Telegram-бота SkillSwipe и связанного с ним приложения (далее «сервис»).

**Оператор:** [оператор], адрес: [адрес], электронная почта: [email].

Обработка ведётся в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных». Основание обработки: согласие пользователя (пункт 1 части 1 статьи 6 закона). Согласие оформлено отдельным документом «Согласие на обработку персональных данных» и даётся нажатием кнопки в боте. Передача текстов ИИ-сервису для определения навыков оформлена ещё одним отдельным согласием.

Сервис предназначен для лиц, достигших 18 лет.

## 2. Какие данные обрабатываются и откуда они берутся

| Данные | Источник |
| --- | --- |
| Идентификатор в Telegram (Telegram ID) | Передаётся Telegram при обращении к боту |
| Имя пользователя в Telegram (username), если оно есть | Передаётся Telegram |
| Язык интерфейса | Настройка Telegram, при необходимости меняется пользователем |
| Режим работы («Ищу проект» или «Ищу экспертов») | Выбирает пользователь |
| Навыки | Определяются автоматически ИИ-сервисом по резюме или описанию пользователя (с его отдельного согласия) |
| Резюме и описания профиля или проекта (файл и текст) | Передаёт пользователь; сервис не сохраняет их после обработки |
| Время и версия согласия | Фиксирует сервис при нажатии кнопки |
| Дата регистрации | Фиксирует сервис |

Оператор не запрашивает телефон, адрес электронной почты, паспортные данные, дату рождения, фотографии и геолокацию. Просим не указывать в сервисе сведения о здоровье, политических и религиозных взглядах и другие специальные категории данных.

## 3. Цели обработки

- создание и ведение аккаунта и профиля пользователя;
- работа сервиса: вход через Telegram, хранение режима и навыков;
- определение навыков пользователя с помощью ИИ-сервиса по резюме или описанию (при отдельном согласии);
- направление сервисных сообщений в боте и ответы на обращения пользователей.

Решения, порождающие юридические последствия для пользователя, на основе автоматизированной обработки не принимаются.

## 4. Как обрабатываются данные

Оператор выполняет сбор, запись, систематизацию, хранение, уточнение (обновление, изменение), использование и удаление данных. Обработка автоматизированная, с использованием средств вычислительной техники.

## 5. Кому передаются данные

- **Хостинг.** Хранение данных осуществляет [хостинг-провайдер] по поручению оператора. Базы данных размещены на серверах на территории Российской Федерации.
- **Telegram.** Пользователь общается с ботом через Telegram. Обработку данных самим Telegram оператор не контролирует, она регулируется правилами Telegram.
- **ИИ-сервис.** Для определения навыков текст резюме или описания передаётся [LLM-провайдер] ([страна провайдера]) по поручению оператора и только при отдельном согласии. Перед отправкой из текста удаляются телефон, адрес электронной почты, ссылки и ФИО. Провайдер получает только очищенный текст.
- **Другие пользователи.** Данные пользователя другим пользователям сервиса не раскрываются.

Иным лицам данные не передаются, кроме случаев, прямо предусмотренных законом.

## 6. Сроки хранения

| Данные | Срок |
| --- | --- |
| Аккаунт, профиль, режим, язык, навыки, сведения о согласии | Пока аккаунт активен |
| Текст резюме и описаний, файл резюме | Не сохраняются после определения навыков |
| Любые данные после удаления аккаунта или отзыва согласия | Удаляются в течение 30 дней |

## 7. Меры защиты

Оператор принимает организационные и технические меры для защиты данных: доступ к данным ограничен лицами, которым он нужен для работы сервиса; учётные данные для доступа к базе данных хранятся отдельно от исходного кода; в журналах работы сервиса не сохраняются тексты персональных данных пользователей; перед отправкой текста в ИИ-сервис из него удаляются телефон, адрес электронной почты, ссылки и ФИО.

## 8. Права пользователя

Пользователь вправе:

- получить сведения об обработке своих данных;
- потребовать уточнения, блокирования или уничтожения данных, если они неполные, устаревшие, неточные, получены незаконно или не нужны для заявленной цели;
- отозвать согласие в любой момент;
- обжаловать действия оператора в уполномоченном органе по защите прав субъектов персональных данных (Роскомнадзор) или в суде.

**Как реализовать права:**

- удалить аккаунт и отозвать согласие можно в боте: «Меню → Мои данные → Отозвать согласие и удалить аккаунт». Отзыв согласия означает удаление аккаунта;
- отозвать согласие на передачу текста ИИ-сервису можно письмом на [email] или удалив аккаунт; без этого согласия навыки не определяются;
- остальные запросы направляйте на [email]. Оператор ответит в течение 10 рабочих дней со дня получения запроса.

## 9. Изменение политики

Оператор публикует новую версию политики с указанием версии и даты. Если меняются состав данных, цели, получатели или сроки, оператор запрашивает новое согласие, и такая обработка не начинается без него.
